# 🚀 TechDelas - Projeto 2 (JavaScript e Local Storage)

> Aplicação web desenvolvida para a disciplina de Programação Web Front-End da UTFPR - Câmpus Cornélio Procópio, expandindo o Projeto 1 com interatividade em JavaScript, manipulação de DOM e Web Storage (Local Storage).

## 📂 Estrutura e Funcionalidades do Projeto 2
- `index.html`: Página principal atualizada com o menu "Adm".
- `login.html`: Página de autenticação e cadastro de novos usuários.
- `adm.html`: Painel administrativo contendo:
  - Formulário de cadastro (Nome e E-mail).
  - Armazenamento em **Local Storage** (chave única com objetos/arrays JSON, incluindo data de envio).
  - Lista não ordenada dinâmica com cada registo.
  - Opção para limpar os campos do formulário.
  - Opção para excluir um item específico (da lista e do Local Storage) com confirmação.
  - Opção para excluir todos os itens (da lista e do Local Storage) com confirmação.
  - Barra de pesquisa com botão dedicado "Pesquisar" e filtro por nome ou e-mail.
- `css/style.css`: Estilização consistente com o Projeto 1.
- `cvj/cvj.html` & `cvl/cvl.html`: Currículos virtuais das integrantes no rodapé.
